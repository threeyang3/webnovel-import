## 行为边界

- 浏览器 URI 回调只打开预览；用户确认前不写笔记、不下载封面。
- 采集书签只发送解析后的作品资料，经本机剪贴板传递；不导出 Cookie、账户凭据或整页 HTML。
- 自动回传核对 URI 中的作品 ID 与剪贴板资料是否一致。手动导入命令则预览当前剪贴板中的有效采集资料。
- 关联既有笔记时，匹配的目标保留至实际保存，不在预览阶段提前清除。
- 刷新继续保护人工字段和人工清空；正文只在首次创建时生成。
- 平台验证页、缺少身份或身份不符的页面会报错；没有用空页面、推荐书或更新时间凑出作品资料。
